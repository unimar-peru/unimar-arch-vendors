## Criterios de Certificación del Módulo

- [ ] VS Code con extensiones instaladas (GitLens, OpenCode, ESLint, Prettier)
- [ ] Git configurado con user.name y user.email
- [ ] Node.js v20+ instalado y verificado (`node --version`)
- [ ] Docker instalado y verificado (`docker --version`)
- [ ] OpenCode instalado y funcionando en VS Code
- [ ] PR `setup-q-track-env` merged en `develop`
