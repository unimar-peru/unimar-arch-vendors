## Acerca de esta Plantilla

Este módulo transforma la visión del Kick-off en contratos de software formales. El equipo aprende a trazar Bounded Contexts del dominio logístico aduanero de UNIMAR y a escribir Historias de Usuario en formato BDD (Given / When / Then) que el equipo de QA puede usar directamente como casos de prueba en el Módulo 4.

---

## Entregable Certificado

Al completar este módulo, el equipo debe haber producido:
- PRD de Q-Track con Visión, Problema, Objetivos, Usuarios y Alcance completos
- Diagrama de Bounded Contexts con al menos 3 contextos
- Backlog Ágil con 10+ historias `Given / When / Then` priorizadas con MoSCoW
- PR mergeado a `develop` aprobado por el facilitador
