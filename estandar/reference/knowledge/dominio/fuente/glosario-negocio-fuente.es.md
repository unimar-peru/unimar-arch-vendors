# Glosario de Negocio — Fuente Reutilizable

> **Propósito:** Estructura canónica para agregar términos al Lenguaje Ubicuo de un producto UNIMAR.
> **Fase SDLC:** 1 — Concepción y Descubrimiento / Transversal
> **Responsable:** Architecture Board + Product Owner
> **Puerta de salida:** Aprobación de Negocio (Gate F1)

---

## Instrucciones de Uso

1. Copia el bloque de entrada canónica para cada término nuevo.
2. Completa todos los campos — no dejar ninguno vacío. Si no aplica, escribir `—`.
3. Ordena las entradas alfabéticamente dentro de cada sección de contexto.
4. Somete el cambio a revisión del Architecture Board antes de hacer merge.
