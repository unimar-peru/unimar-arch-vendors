# ADR-0049: Política de Naming Semantics y Clean Code

> **Estado:** Supersedido por [ADR-0056](./0056-convenciones-nombre-diseno-empresarial.es.md)
> **Fecha:** 2026-06-05
> **Decisores:** Architecture Board

## Contexto

Disciplina de naming: nombres deben comunicar intención, no implementación. Esta ADR consolidaba las reglas de nomenclatura y clean code aplicables a los artefactos de código.

## Estado: Supersedido

> **Nota:** Esta ADR fue superseída por [ADR-0056: Clean Code como Base de Ingeniería de la Suite](./0056-convenciones-nombre-diseno-empresarial.es.md), que es la versión vigente. Aplíquese ADR-0056.
