# ADR-0049: Política de Naming Semantics y Clean Code

> **Estado:** Pendiente de Importación
> **Fecha:** 2026-06-05
> **Decisores:** Architecture Board

## Contexto

Disciplina de naming: nombres deben comunicar intención, no implementación. Esta ADR consolida las reglas de nomenclatura y clean code que se aplican a todos los artefactos de código.
