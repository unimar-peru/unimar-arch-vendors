HOJA 0 — SÍNTESIS EJECUTIVA PARA DECISIÓN INMEDIATA

Dimensión Síntesis para la Dirección
Problema El equipo de 20 personas (analistas, desarrolladores, QA) necesita herramientas de IA para acelerar el desarrollo bajo estándares unimar_arch con el framework BMAD Spec-Driven. Sin licencias, el equipo produce código sin asistencia, lento y propenso a desviarse de los estándares.
Objetivo Dotar al equipo de IA generativa para: (1) orquestar especificaciones técnicas con Claude, (2) asistir en codificación diaria con OpenCode, (3) mantener calidad arquitectónica consistente.
Modelo recomendado ⭐ Escenario Base Híbrido → USD 810/mes

✅ Por qué sí: Cubre calidad arquitectónica (Claude $200 para Arquitecto y Analista Principal) + productividad diaria (OpenCode Go para 5 líderes + OpenCode Gratuito para 15 devs/QA).
❌ Por qué dudar: OpenCode Gratuito tiene límites de 200 peticiones/5h que podrían saturarse en horas pico. Sin Copilot, el autocompletado en VS Code es menos fluido.
Alternativa ⚠️ Escenario Híbrido + Copilot → USD 905/mes

Agrega GitHub Copilot Business para 5 líderes. Mejora la velocidad de codificación boilerplate pero incrementa el costo en USD 95/mes.
Inversión total USD 810/mes para todo el equipo de 20 personas. Menos de USD 41/persona/mes.

Decisión del Comité Ejecutivo: Aprobar el Escenario Base (USD 810/mes) con Claude $200 (2 licencias) + Claude Pro $20 (18 licencias) + OpenCode Go (5 líderes). Evaluar en Fase 3 (mes 7-12) la incorporación de GitHub Copilot Business si la velocidad de codificación boilerplate lo justifica.

2. ANÁLISIS Y RECOMENDACIÓN ESTRATÉGICA

Basado en el contexto del equipo (20 personas, estándar unimar_arch, uso de BMAD para automatización spec-driven, y presupuesto ajustado), la herramienta más recomendada como núcleo estratégico es CLAUDE (Tier Arquitecto/Analista).

Justificación de la elección: El éxito del enfoque Spec-Driven con BMAD depende críticamente de la precisión en la interpretación de requisitos y la generación de especificaciones técnicas complejas. Claude (especialmente el tier de USD 200) supera a las demás herramientas en razonamiento profundo, manejo de contexto largo y seguimiento de estándares de software. Si bien es costoso, basta con 2 licencias (Arquitecto y Analista Principal) para orquestar a los agentes de IA que luego generarán el código base, el cual será validado por el resto del equipo con herramientas más económicas.

4. VENTAJAS Y DESVENTAJAS DEL MODELO RECOMENDADO (BASE: USD 810)

Ventajas Desventajas
• Enfoque en calidad: Las 2 licencias caras aseguran que la “cabeza” del proyecto (Arquitectura y Especificaciones) sea de primer nivel.
• Ahorro significativo: El 75% del equipo usa herramientas gratuitas o de bajo costo (USD 10).
• Escalabilidad: Permite activar Copilot o pasar a OpenCode Black/Go masivamente según la carga de trabajo futura.
• Alineación con BMAD: Claude es el mejor para orquestar agentes autónomos y validar el cumplimiento del estándar unimar_arch.		 • Riesgo de límites: Los 15 usuarios con OpenCode Gratuito podrían quedarse sin peticiones en horas pico.
• Falta de Copilot: El autocompletado en VS Code no será tan fluido como con Copilot, lo que puede ralentizar la codificación pura (boilerplate).
• Gestión descentralizada: Al tener 3 herramientas diferentes (Claude, OpenCode), la gestión de facturación y acceso es más compleja.

6. CONCLUSIÓN FINAL

La adquisición recomendada es:

  1. Claude (Tier USD 200): 2 licencias para Arquitecto y Analista Principal (Obligatorio).
  2. Claude (Pro): 18 licencias para el resto del equipo (Obligatorio).
  3. OpenCode (Go): 5 licencias para Líderes Técnicos (Recomendado).
  4. OpenCode (Gratuito): Para los 15 miembros restantes (Base).
  5. GitHub Copilot: Evaluar en Fase 3, no adquirir inicialmente para mantener el costo en USD 810/mes.

Este plan asegura que la calidad arquitectónica (Claude) y la eficiencia operativa (OpenCode) estén cubiertas sin exceder el presupuesto inicial, permitiendo una evolución natural hacia herramientas más potentes según las necesidades del proyecto.
