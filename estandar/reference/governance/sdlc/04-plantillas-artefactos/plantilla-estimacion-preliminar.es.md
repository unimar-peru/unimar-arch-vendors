## Propósito

Proveer una estimación de alto nivel (tallas relativas, orden de magnitud) de esfuerzo técnico, OPEX / CAPEX y tamaño de equipo, para evaluar la viabilidad financiera frente al caso de negocio.

## Reglas de Autoría

- Usa el archivo fuente como punto de partida para cada nueva estimación.
- Este documento requiere un Caso de Negocio ROI aprobado como entrada.
- Usa tallas relativas (S/M/L/XL); no des estimaciones en horas-hombre.
